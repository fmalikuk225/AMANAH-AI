# AMANAH AI — Final Candidate

AMANAH AI is a bilingual (English/Arabic) digital-resilience MVP for AI-era Islamic content.

## Core experience
- **CHECK**: inspects source traceability and trust-risk signals without issuing religious verdicts.
- **TRAIN**: controlled scenarios teach users when to trust, verify, skip, or report content.
- **ADAPT**: later practice is targeted using observed session weaknesses.
- **PROFILE**: session-only learning indicators across five resilience dimensions.

## Safety boundary
AMANAH does not issue fatwas, certify religious claims as universally true/false, or claim universal deepfake detection. Where evidence is insufficient, it explicitly recommends verification with traceable sources or appropriate qualified guidance.

## Run locally
Open `index.html` in a modern browser. No login, database, or API key is required for the competition MVP.

## Competition build notes
- English + Arabic with RTL support
- Controlled/synthetic training scenarios are clearly labelled
- No fabricated user-study results or validated psychometric claims
- No secrets, API keys, or database dumps
